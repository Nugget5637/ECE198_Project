CCCARE Exercise Tracker

ECE 198 Project

This website shows the results of a group exercise class. A camera watches each person and counts their reps and checks their form. An ESP32 measures how hard they are working (exertion).

Choose a page

  • Instructor dashboard - set up the class, start a session and watch everyone
  • Patient page - see your own workout while the session runs
  • Session results - see how the class did, and progress over past sessions
  • Exercise list - all the exercises we track

How to try it

  1. Open the instructor dashboard, enter the names and workouts, and press Start session.
  2. In another tab of the same browser, open the patient page and pick a name. It follows the session.
  3. Press End session on the instructor dashboard to see the results.

Prototype. A simulator makes up the reps, form quality and exertion. Data is saved in this browser only.
