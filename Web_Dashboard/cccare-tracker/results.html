Progress

Each person's score in every session they have been in.

How the score works: score = (1 - reps off / reps planned) x average form quality. "Reps off" is how far each set was from the plan, so stopping short and doing too many both lose points. For example, 2 sets of 10 done as 10 and 7 at 80% quality gives (1 - 3 / 20) x 80% = 68%.
